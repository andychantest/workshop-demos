# LUNCH·O·MATIC 午餐吃什麼

## 專案概述

一個「現在午餐吃什麼」的決策輪盤 Demo App。當使用者猶豫不決時，把常吃餐廳丟進轉盤，按下按鈕讓命運決定。屬校園／社群日常痛點（午餐選擇困難）的快速原型。

- **目標使用者**：學生、上班族等每天煩惱午餐的人
- **性質**：**純展示用 Demo** — 無後端、無法真實多人使用
- **技術棧**：單一 HTML 檔，原生 CSS + Vanilla JS，資料存於瀏覽器 `localStorage`
- **多語系**：繁中（預設）／簡中／英文 三語即時切換（記憶於瀏覽器）

## 核心功能

### 1. 轉盤抽籤（主要功能）
- Canvas 繪製彩色輪盤，依「當前可選清單」動態分段
- `requestAnimationFrame` + 三次方 ease-out 慣性動畫（約 4.2 秒）
- 指針固定於頂部，計算最終落在哪一段並顯示結果卡
- 動畫過程以 WebAudio 產生每跨段的「噠」聲，結束時播勝出音效

### 2. 餐廳庫
- 預置 14 家種子餐廳（台式、港式、日式、韓式、泰式、美式、火鍋、輕食、甜品等）
- 每個餐廳欄位：`id, name, emoji, cat（分類）, price（1~3）, spins（抽中次數）, excl（是否排除）`
- 可新增（Modal 表單：emoji、名稱、分類、價格）、可刪除

### 3. 篩選
- 分類 Chip（依現有餐廳動態產生，含數量）
- 價格分段（$ 銅板 / $$ 日常 / $$$ 犒賞）
- 只從符合條件的餐廳分段轉盤

### 4. 不喜歡／排除
- 結果卡「👎 不喜歡」→ 該餐廳永久排除（存 localStorage），自動重轉一輪
- 排除列顯示可點 ✕ 復原放回

### 5. 決定紀錄
- 每輪結果寫入歷史（前 16 筆），顯示時間與圖示
- 點歷史項目可「指定轉到那家」

### 6. 其他
- 統計（餐廳數、已決定次數）、空間鍵快速轉盤、重置按鈕（`confirm` 確認後清空 localStorage 恢復種子）

### 7. 多國語言（i18n）
- `zh-TW`（繁中，預設）／ `zh-CN`（簡中）／ `en`（英文）
- 頂欄三鍵切換，即時重繪全部介面與轉盤文字
- 種子餐廳以「語意鍵」`k` 儲存，切換語言時名稱自動轉譯；使用者自訂餐廳則保留輸入原名
- 分類／價格以**分類鍵（cat）與價格數字**儲存，顯示時再依語言翻譯，資料與語言徹底分離
- 語言偏好寫入 `localStorage`（key：`lunchom_lang`），重整後延續；「重置」不影響語言偏好
- 舊版資料（v0.1，中文分類字串＋中文名稱）載入時自動遷移：分類轉為分類鍵、中文名稱符合種子者補上 `k`（餐廳庫與歷史紀錄皆遷移），之後便會隨語言轉譯；使用者自訂餐廳名稱不在種子對照表內，保留原名

### 邊界情況
- 可選清單 < 2 家 → Toast 提示「至少要 2 家才能轉」
- 名單全空 → 轉盤畫面上顯示引導文字，提示先新增
- 篩選後無結果 → 轉盤顯示空狀態
- 歷史點擊的餐廳已被移除／排除 → Toast 提醒

### 錯誤處理
- `localStorage` 讀取失敗（JSON 損壞）→ 回退到種子資料
- 寫入失敗（瀏覽器禁用）→ Toast 提示
- WebAudio 初始化失敗 → 靜默略過音效，不影響功能

## 資料結構（localStorage key：`lunchom_v1`）

```json
{
  "restaurants": [ { "id": 1, "k": "pork", "name": "", "emoji": "🍱", "cat": "tw", "price": 2, "spins": 0, "excl": false } ],
  "history":     [ { "k": "pork", "name": "", "emoji": "🍱", "cat": "tw", "ts": 1766900000000 } ],
  "decided": 12,
  "lastId": 15
}
```

- `k`：種子餐廳的多語名稱鍵（`null` 表示使用者自訂，沿用 `name`）
- `cat`：分類鍵（`tw/hk/jp/kr/th/us/it/hotpot/light/west/dessert`），顯示時翻譯
- 另存語言偏好 key：`lunchom_lang`
- 無資料庫、無 RLS、無 Trigger —— 資料 100% 在瀏覽器端

## 設計決策

- **視覺**：夜市霓虹 × 抽籤機風格 — 暗色暖底（`#17110e`）+ 高飽和糖果色段（珊瑚、琥珀、薄荷、天藍、紫、粉紅），有別於常見的淺色 AI 風格；字型使用 Google Fonts「Baloo 2 + Noto Sans TC/SC」
- **指針方向**：箭頭尖端朝下（`M23 54`）指向轉盤，頂部 bob 動畫僅垂直浮動，避免側偏
- **轉盤標籤自適應**：受 `measureText` 實測寬度限制，字級自動縮減（下限 9px），仍放不下則以「…」截斷——英文長名（如 Korean Fried Chicken）不再溢出扇區
- **單機架構**：刻意不接後端／Supabase，因為這是「天生單人可用」的工具型 App，純本機儲存反而合理
- **Demo 誠實標註**：頁尾明確標示「僅展示用、資料只存本機、非真實服務」

## 設定與部署

- 無需建置、無依賴，直接雙擊 `index.html` 即可執行
- 部署：上傳至 GitHub 後以 Vercel（或 GitHub Pages 備援）靜態託管
- 線上版需注意 Google Fonts CDN 需可連線；離線使用時字型將回退為系統字型
